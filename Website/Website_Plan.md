# **SAM New York Website Plan**

SAM New York is a Singapore Math enrichment center franchise in New York.  SAM stands for Seriously Addictive Mathematics.

## **1\. Site Architecture**

# The site follows a streamlined information architecture optimized for parent decision-making and SEO depth. The primary user journey is: Learn what SAM is → Understand why it’s different → See proof it works → Book an assessment.

| Page | Purpose | Priority |
| ----- | ----- | ----- |
| Home | Hero, value prop, trust signals, CTA → assessment booking | Phase 1 (Launch) |
| Why S.A.M | Methodology, CPA approach, SAM vs. Others comparison | Phase 1 |
| Programs | Grade-level breakdown (Pre-K through Grade 8\) | Phase 1 |
| Singapore Math | What it is, TIMSS rankings, why it works (long-form for SEO) | Phase 1 |
| Book Assessment | Link to Assessment Page | Phase 1 |
| Testimonials | Parent stories, student spotlights, video testimonials | Phase 1 |
| About / Our Team | Founder bio, Center director bio, trainer certifications, mission | Phase 1 |
| FAQ | Common parent questions with FAQ Schema markup | Phase 1 |
| Blog / Resources | Articles, math tips, Singapore Math explainers | Phase 1  |
| Neighborhood Pages | Location-specific landing pages for local SEO | Phase 1 |
| Gallery | Photos from the center, events, student work | Phase 2 |
| Careers | Job postings for trainers and staff | Phase 2 |
| Online Quiz | Interactive math diagnostic for lead generation | Phase 3 |
| Parent Portal | Student progress dashboard (login required) | Phase 3 |

## **3\.  Key Page Specifications**

### Why S.A.M Page

# •        Detailed explanation of the CPA (Concrete-Pictorial-Abstract) methodology with visual examples

# •        12 problem-solving heuristics overview (bar model method highlighted)

# •        Award badges and certifications

# •        Full comparison table (S.A.M vs. traditional tutoring) — expanded version of homepage comparison

# •        TIMSS results showing Singapore ranked \#1

# •        CTA: Book Assessment

# •        Target length: 1,500+ words (long-form for SEO value)

### Programs Page

# •        Separate sections for each grade band with detailed descriptions

# •        Class format, session frequency, group size (max 5 in-class, max 2 online, 1-on-1 available)

# •        Pricing transparency: “Starting from $X/month” or “Contact us for pricing” with clear link

# •        SAM complements all school curricula (public, private, charter, homeschool)

### Assessment 

### •        Link to a new tab with Assessment process (to be built separately)

# •        “What to expect at your assessment” section (duration, what the child will do, what parents will learn)

# •        No-pressure messaging: “The assessment is free and there is no obligation to enroll”

# •        Include Event schema markup for assessment sessions (rich results in Google)

### FAQ Page

# •        Accordion-style expandable questions (15–20 questions)

# •        Core questions: How is S.A.M different from Kumon/Mathnasium? What age should my child start? How often are classes? What if my child is already advanced? Do you follow Common Core? What is the class size? How are trainers certified?

# •        FAQ Schema markup (required). Every Q\&A pair must be wrapped in FAQPage structured data. This enables Google to display expandable answers directly in search results — zero SAM franchise sites currently do this.

### About / Our Team Page

# •        Founder and Center director full bios with personal photo

# •        Trainer certifications and qualifications

# •        Mission and values statement localized to New York

# •        Brief history of S.A.M (founded 2010, 200+ centers in 20+ countries)

### Blog / Resources (Phase 1\)

# •        WordPress blog with categories: Singapore Math, Parenting Tips, Student Spotlights, NYC Education News

# •        Launch with 8–10 foundational articles (see Content Calendar below)

# •        Publishing cadence: 4 articles per month minimum

# •        Each article: 800–1,500 words, one target keyword, internal links to Programs/Why SAM/Book Assessment pages

# •        Yoast SEO readability and keyword optimization for every post

### **Neighborhood Landing Pages (Phase 1\)**

# •        Create one landing page per target neighborhood: Upper West Side, Upper East Side, Midtown, plus 2–3 others based on center location

# •        Each page: 500–800 words covering nearby schools served, partner businesses (retail, doctors, other kids programs), links, travel directions, local parent testimonials

# •        Target keywords: “math tutoring \[neighborhood\]”, “Singapore math \[neighborhood\]”, “math enrichment near \[school name\]”

# •        LocalBusiness schema markup on every neighborhood page with specific address and service area

## **4\. SEO & Content Strategy**

### Technical SEO Requirements (Launch Day)

# •      Schema Markup (structured data): LocalBusiness schema on every page (name, address, phone, hours, geo coordinates). FAQPage schema on FAQ page. Course schema on Programs page. Event schema on Book Assessment page.

# •        Core Web Vitals: Page load under 3 seconds on mobile. Pass all Google metrics (LCP, FID, CLS). Test with PageSpeed Insights before launch.

# •        Mobile-first design: 60%+ of parent searches happen on mobile. Design and test mobile-first.

## **5\. Design and Brand Specifications**

### **C**olor Palette

| Element | Color | Hex | Usage |
| ----- | ----- | ----- | ----- |
| Primary | S.A.M Blue | \#1A5276 | Headers, navigation, body text accents |
| Secondary | S.A.M Orange | \#E67E22 | CTA buttons, highlights, accents |
| Background | White | \#FFFFFF | Page backgrounds |
| Light Accent | Light Blue | \#D6EAF8 | Feature cards, hover states |
| Text | Dark Gray | \#333333 | Body text |
| Subtle | Medium Gray | \#7F8C8D | Captions, footer text |

### Typography

# •        Primary font: Arial or Open Sans (clean, modern, universally supported)

# •        Headings: 24–36px, bold, brand blue

# •        Body text: 16px, dark gray, 1.6 line height for readability

# •        CTA buttons: 16–18px, bold, white text on orange background, rounded corners

### Photography Guidelines

# •        Use real photos of S.A.M students (diverse representation essential for NYC)

# •        Show children actively engaged: manipulating blocks, drawing diagrams, working with a trainer

# •        Avoid generic stock photos of children at desks

# •        Include photos of the actual NYC center (interior, exterior, classroom setup)
